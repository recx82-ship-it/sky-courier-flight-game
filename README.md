Sky Courier — The Kestrel Isles is an original 2D flight game. Fly the Kestrel mail plane through 7 glowing rings over a named island chain — Tern Rock, Beacon Point, Palm Cay, Ember Peak, Skerry and Gulltown — then bring her down on runway 07 at Gulltown Airstrip. A crosswind pushes the plane sideways, the lit instrument panel shows altitude, speed, heading and vertical speed, and the bottom strip carries an artificial horizon, a compass tape, a throttle gauge and a wind readout. Engine hum, wind, ring chimes, touchdown thuds and a landing fanfare are all synthesised in WebAudio — no audio files. Three attempts per run, with a score for rings flown, landing softness, time against par and a bonus for a perfect route. Steer with the arrow keys or the mouse, throttle with Shift/Ctrl, P to pause, M to mute, R to retry after a crash. It plays offline in a desktop browser from static files, with no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
